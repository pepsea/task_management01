# Task & Idea Hub

個人用のタスク管理（ガントチャート）・アイディア保管庫・ブレスト・Markdown メモ帳を扱うローカル Web アプリ。

- TODO: ガントチャート（日・週・月表示、ディシジョンポイント、今日のタスク、リンクリスト、ブレスト）
- IDEA: アイディア保管庫（タグ・優先・並べ替え・タスク化）
- NOTES: Markdown メモ帳（Typora 風の編集、タグ、ピン留め、エクスポート）
- REGISTRATION: 領域・関連項目・タグの管理
- ARCHIVE: アーカイブしたアイディア・メモ
- SETTING/DATA: 画面の大きさ・バックアップ・データのエクスポート・パスワード変更

## Docker で動かす（おすすめ）

```bash
docker compose up -d
```

ブラウザで http://localhost:5003 を開く。

- 停止: `docker compose down`
- アプリを更新したとき（git pull の後など）: `docker compose up -d --build`
- ログ: `docker compose logs -f`
- データは `./data/app.db` に保存され、コンテナを作り直しても消えない
- 標準では同じネットワークの他の PC からも `http://<サーバーのアドレス>:5003` で開ける（ログインが必要）。このパソコンからだけに限る場合は `docker-compose.yml` の `ports` を `"127.0.0.1:5003:5003"` に変える
- サーバーのファイアウォールが有効な場合は 5003 番ポートを開ける
- インターネットには公開しない（通信が暗号化されない http のため）
- Linux でも `docker compose up -d` だけで動く。`./data` が無い・書き込めない場合は、起動時にコンテナが `./data` の所有者を UID 1000 に変更する（ホスト側でファイルを直接触るときは `sudo` が必要になることがある）

## Docker を使わずに動かす

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
./run.sh
```

ブラウザで http://localhost:5003 を開く。

## ログイン

- 最初に開くと「初回設定」画面が出るので、ユーザー名とパスワード（8 文字以上）を決める。アカウントは 1 つだけ
- ログインした状態は 30 日間保たれる（使うたびに延長）。右上の **ログアウト** でログアウト
- パスワードは **SETTING/DATA** タブの「パスワード変更」で変えられる（他のブラウザのログインは解除される）
- ログインに 5 回失敗すると 10 分間ログインできない
- パスワードを忘れたときは、サーバーで次のコマンドを実行して再設定する（すべてのログインが解除される）

```bash
docker compose exec -u appuser app python -m app.cli reset-password
```

Docker を使わない場合は `.venv/bin/python -m app.cli reset-password`。

## 画面の使い方

画面の上部のタブ（**TODO / IDEA / NOTES / REGISTRATION / ARCHIVE / SETTING/DATA**）で画面を切り替える。
入力した内容はすべて自動でサーバー（`data/app.db`）に保存される。

### はじめに：REGISTRATION

タスクの「領域」と「関連項目」は、登録したものから選ぶ。最初に **REGISTRATION** タブで登録しておく。

- **領域**：仕事・プライベート・学習など、タスクの大きな分類。登録すると色が自動で付き、ガントのバーがその色になる。色の丸をクリックすると色を変えられる
- **関連項目**：プロジェクト名や相手先など。領域とは別に管理し、どの領域のタスクでも使える
- **タグ（アイディア・メモ共通）**：アイディアやメモの編集欄で入力すると自動で作られる。ここでは名前・色の変更と削除ができる
- 名前の欄を書き換えて Enter（または欄の外をクリック）で名前を変更できる。変更は既存のタスクにも反映される
- タスクで使われている領域・関連項目は削除できない

### TODO

左がガントチャート、右がリンクとブレスト。

**ガントチャート**

- **＋ タスク** でタスクを追加する。領域・関連項目・タスク名・開始日・期限・優先度（高・中・低）・メモ・リンクを入力できる
- 行をクリックすると編集ダイアログが開く（削除もここから）
- バーをドラッグすると、期間の長さはそのままで開始日・期限をずらせる。バーの左端・右端をドラッグすると、開始日・期限を個別に変えられる（どちらも 1 日単位）
- **完了** のチェックで完了にする。完了したタスクは薄く表示され、一番下に移る。完了から 2 日たつと TODO から消え、**ARCHIVE** タブの「タスク」に移る
- **☀**（行の先頭）を押すと「今日のタスク」になり、行が黄色で強調されて一番上に並ぶ。翌日になると自動で外れる。ツールバーの **☀ 今日 n** で今日のタスクだけを表示できる
- 並び順：今日のタスク → その他の未完了 → 完了。それぞれの中は期限の日付の早い順、同じ日付は優先度の高い順（高 → 中 → 低）
- **登録** の列にはタスクを登録した日を表示する（マウスを乗せると時刻も見える）
- 表の見出し（☀・関連項目・タスク名・登録・開始・期限・優先・完了）をクリックすると、その項目の順に並べ替える。もう一度で逆順（▲ / ▼）、3 回目で標準の並びに戻る。同じ値のものは標準の並び。選んだ並びはブラウザに保存される。登録で並べると、同じ日でも登録した時刻の順になる
- 期限まで残り 2 日以内の未完了タスクは期限が赤い背景に、期限切れは濃い赤の背景になる
- タスクにリンクを登録すると、タスク名の下に小さく表示される。クリックで新しいタブが開く
- タスク名にマウスを乗せるとメモが見られる
- **日 / 週 / 月** で 1 列の単位を切り替える。**◀ ▶** で期間を移動し、**今日** で今日に戻る
- 日付の部分（バー以外の空いた所）を左右にドラッグすると、期間をスライドできる（日表示は 1 日、週表示は 1 週、月表示は 1 か月ずつ）。トラックパッドの左右スワイプでも動く
- ガントのバーの中に「領域 / 関連項目」が表示される（短いバーでは末尾が「…」になる）
- ツールバーの **検索** 欄に文字を入れると、タスク名・領域・関連項目・メモ・リンクに含むタスクだけを表示する（空白で区切るとすべてを含むもの）
- 表の見出しの右端をドラッグすると列幅を変えられる（ダブルクリックで元の幅に戻す）
- タスク名の見出しの **◂** で、登録・開始・期限・優先・完了の列をまとめて折りたためる（**▸ 詳細** で戻す）。折りたたみ中は、期限が近い・過ぎたタスクのタスク名が赤字になる

**定期タスク**

- **＋ 定期タスク** で、繰り返すタスクの一覧が開く。**＋ 定期タスクを追加** で登録し、一覧の行をクリックで編集・削除
- 繰り返しは **毎月 ○日**（31 日など無い月は月末）・**毎月 第○ ○曜日**（第1〜第4・最終）・**毎週 ○曜日** から選ぶ
- 繰り返しの日を期限にしたタスクが、1 か月先の分まで自動で作られる（タスク名の前に 🔁）。「何日前から始めるか」で開始日を前にずらせる（土日を除いた日数で数える）
- 作られたタスクは普通のタスクと同じように完了・編集・削除できる（完了から 2 日で ARCHIVE に移る）
- 定期タスクを変更すると、これから先の未完了の回が作り直される。削除すると、これから先の未完了の回も消える（完了した回・期限の過ぎた回は残る）
- 「この日以降の回を作る」より前の回や、登録した日より前の回はさかのぼって作らない

**ディシジョンポイント**

- **＋ ディシジョン** で、重要な会議や判断日などを日付（と時刻）付きで登録する
- ガントの「ディシジョン」行に ◆ と名前が表示され、その日に紫の縦線が引かれる。ディシジョンの行は 1 段で固定。同じ日や近い日付のものは重ねて表示され、◆ にマウスを乗せると名前が見える
- ◆ をクリックすると修正・削除できる

右側のリンクとブレストは、ガントとの間にある縦長の帯（**▶ リンク・ブレスト**）をクリックするとまとめてたためる（ガントが横幅いっぱいに広がる）。右端の帯（**◀ リンク・ブレスト**）をクリックすると元に戻る。

**リンク**（右上）

- **＋** でよく使うリンクを登録する。✎ で編集、× で削除、⋮⋮ をドラッグして並べ替え
- Web（`https://…`）はクリックで新しいタブが開く
- 社内サーバーや PC のパス（`C:\…` `\\サーバー\共有\…` `file://…`）は、ブラウザの制限で直接は開けないため、クリックするとパスがコピーされる。エクスプローラーや Finder のアドレス欄に貼り付けて開く
- `smb://サーバー/共有` の形で登録すると、Mac ではクリックで Finder が開く

**ブレスト**（右下）

- 思いついたことを入力して Enter で書き留める。思いついた日時も記録される
- **→保管庫** でアイディア保管庫に移す（思いついた日時は引き継がれる）。**×** で削除

### NOTES（Markdown メモ帳）

- **＋ 新しいメモ** でメモを作る。タイトルを入力して Enter で本文へ
- 本文は Markdown で書くと、その場で整形される（Typora 風）
  - クリックしたブロック（段落や表など）だけが Markdown の原文に戻り、編集できる
  - ↑ ↓ で前後のブロックへ移動、Enter 2 回で次のブロックへ、Esc で編集を終える
  - 箇条書きの行で Enter を押すと、次の行にも記号が続く。Tab / Shift+Tab で字下げ
  - チェックリスト（`- [ ] やること`）のチェックボックスはクリックで切り替えられる
  - 見出し・太字・斜体・取り消し線（`~~ ~~`）・コード（`` ` ``）・表・引用・リンク・区切り線が使える
  - 本文のブロックを編集中に文字を選び、書式バーの黄色の四角（蛍光ペン、`==文==`）や色の丸（赤・青・緑・橙・紫）を押すと、蛍光ペン・文字色を付けられる
  - 蛍光ペンと文字色はこのアプリ独自の書き方なので、エクスポート・コピーでは外れて中の文章だけになる
- 📅 でメモの日付を変える（作成時は今日）
- 「＋タグ（Enter）」でタグを付ける。タグの × で外す
- **📋 コピー** で Markdown の文章をクリップボードにコピー、**⬇ エクスポート** で Markdown ファイル（`日付_タイトル.md`）として保存する
- **アーカイブ** でメモ帳から外す（ARCHIVE タブから戻せる）
- 一覧の **☆** をクリックすると **★**（ピン留め）になり、先頭に固定される
- 一覧の上の **日付順 / 手動** で並び順を切り替える。⋮⋮ をドラッグするといつでも並べ替えられる（日付順のときにドラッグすると「手動」に切り替わる）
- 検索欄とタグのプルダウンで絞り込める

### IDEA（アイディア保管庫）

- タイトルを入力して **登録**（または Enter）でアイディアを追加する
- 一覧のアイディアをクリックすると右側で編集できる。もう一度クリック、× ボタン、Esc で閉じる
- 入力は自動保存される。**保存** ボタンですぐに保存することもできる
- 「＋タグ（Enter）」でタグを付ける
- **タスク化** を押すと TODO 画面に移り、そのアイディアをタスク名にしたタスク作成ダイアログが開く。タスク化したアイディアには一覧で ✓ が付く
- **☆** をクリックすると **★**（優先）になり、黄色で強調されて先頭に並ぶ
- ⋮⋮ をドラッグして並べ替える（★ の付いたものと付いていないものの間はまたげない）
- **アーカイブ** で保管庫から外す（ARCHIVE タブから戻せる）
- 検索欄とタグのプルダウンで絞り込める

### ARCHIVE

- 上の **タスク / アイディア / メモ** で表示を切り替える
- **タスク**：完了から 2 日たったタスクが、完了の新しい順に並ぶ。行をクリックするとメモ・リンク・期間が開く
  - **戻す** で未完了に戻し、TODO に表示する
  - **⬇ CSV** でアーカイブしたタスクを CSV（Excel で開ける）でダウンロードする
  - 完了から 1 年たったタスクは自動で削除される（必要なら CSV で残しておく）
- 1 件ずつ 1 行で表示される。行をクリックすると本文が開く
- **戻す** で保管庫・メモ帳に戻す。**削除** で完全に削除する
- メモの行の **📋** で Markdown をコピー、**⬇** で Markdown ファイルとして保存できる

### SETTING/DATA

- **表示**：「画面の大きさ」で画面全体の表示倍率（70〜120%）を変える。ブラウザごとに保存されるので、Windows（表示スケール 125%・150% で文字が大きく見える）だけ 80〜90% にする、といった使い分けができる
- **バックアップ**：「＋ 今すぐバックアップ」で作成、一覧から復元・ダウンロード・削除（詳しくは下の「データ」）
- **データのエクスポート**：すべてのデータを ZIP でダウンロード
- **パスワード変更**：現在のパスワードと新しいパスワード（8 文字以上）を入力して変更

## データ

- 保存先: `data/app.db`（SQLite）。git 管理外
- バックアップ: アプリを止めてから `data/app.db` をコピーする
- バックアップ: **SETTING/DATA** タブの「バックアップ」で、いつでも「＋ 今すぐバックアップ」で作成できる（`data/backups/` に保存）
  - 一覧から **復元** するとすべてのデータがその時点に戻る。戻す前の状態は「復元前の自動保存」として残るのでやり直せる
  - ログインのアカウントとパスワードは復元しても変わらない
  - 作成から 30 日たったバックアップは自動で削除される。⬇ でファイルをダウンロードして手元に残すこともできる
  - 手動で削除するときは、確認の欄にそのバックアップの日付を 8 桁の数字（例：`20260929`）で入力する（誤って消さないため）
- エクスポート: **SETTING/DATA** タブの「⬇ すべてのデータをダウンロード（.zip）」で、すべてのデータを ZIP でダウンロードできる
  - `data.json`: すべてのデータ（タスク・ディシジョン・アイディア・ブレスト・メモ・領域・関連項目・タグ・リンク）
  - `tasks.csv` / `ideas.csv`: Excel で開ける一覧（tasks.csv にはアーカイブしたタスクも含む）
  - `notes/`: メモを 1 件ずつ Markdown で（アーカイブしたメモは `notes/archive/`）
  - ログインのパスワードとログイン状態は含まない
